# 공공기관 기능개혁 앵커 페이지 설계 초안

작성 기준일: 2026-09-21  
기준 커밋: `899eecb` (`origin/main`)

## 1. 페이지의 역할

새 페이지는 정부 발표를 다시 요약하는 자료실이 아니라, 정부가 약속한 조직·비용·권한의 변화가 실제로 이행되는지를 시민 관점에서 비교하는 장기 감시 장부로 만든다.

핵심 질문은 다음 한 문장으로 통일한다.

> 기관은 줄고, 국민 부담과 정부 권한도 줄어드는가?

기존 핫이슈 기사 `LH는 빚을 나누고, 발전 5사는 권력을 합친다`는 문제 제기와 유입을 담당한다. 새 앵커 페이지는 정부 전체 계획, 법률 절차, 비용과 부채, 실제 시민 영향을 누적해서 보여준다.

## 2. 숫자 사용 원칙

- 정부가 발표한 `109개`는 개편에 관련된 모든 기관의 단순 명단 수가 아니라 통합·청산 등으로 줄이겠다는 **감축 목표**다.
- 발전 5사를 1개 법인으로 합치면 관련 기관은 5개지만 감축 수는 4개다.
- LH 기능 분리는 같은 계획에 포함됐지만 기관 수는 오히려 늘 수 있다.
- 공항 통합은 즉시 확정된 과제가 아니라 지방공항 활성화 경과를 본 뒤 다시 검토한다는 단계다.
- 따라서 공개 화면에는 `대상 109개 기관` 대신 `정부 감축 목표 109개`라고 표시한다.
- 전체 장부는 `개혁 과제`, `관련 기관`, `개편 전 수`, `개편 후 예정 수`, `순증감`, `확정 단계`를 별도 필드로 관리한다.

## 3. 공식 발표에서 우선 확인된 구조

정부는 2026년 9월 3일 제11차 공공기관운영위원회 심의·의결을 거쳐 다음 세 유형의 감축 목표를 발표했다.

| 개혁 유형 | 정부 감축 목표 | 공개 본문에서 확인된 대표 과제 |
| --- | ---: | --- |
| 전략적 구조개혁 | 15 | 발전 5사 통합, 항만공사 4사 통합, 석유·가스공사 통합, 석탄공사 청산, LH 기능 분리, 고속철도 일원화, 공항 통합 재검토, 전시·관람기관 통합 |
| 유사·중복기능 일원화 | 11 | 방송광고·시청자미디어, 노사발전·노동교육, 첨단의료재단, 중소기업유통·공영홈쇼핑 통합, K-마루 해외거점 일원화 |
| 자회사·소규모기관 통합 | 83 | 한국잡월드 자회사 흡수, 금융 자회사 7개, 항만 자회사 5개, 중기부 시설관리 자회사 3개, 식품안전·건설산업·공간정보·국악 분야 기관 통합 |
| 합계 | 109 | 감축 목표이며 단순 대상기관 수가 아님 |

공식 보도문 본문은 대표 사례만 열거한다. 전체 세부 기관명은 정부 첨부자료와 각 부처 후속 발표를 대조해 확정한 뒤 공개 장부에 넣는다. 이름이나 감축 수가 불명확한 기관은 추정해서 채우지 않는다.

## 4. 첫 화면 정보 구조

### A. 30초 요약

- 정부 감축 목표: 109개
- 현재 단계: 정부 계획 발표 및 부처별 후속계획 착수
- 완료된 통합: 확인된 완료 건수만 표시
- 법률 개정 필요: 확인된 과제 수만 표시
- 비용 공개: 공개된 과제 수 / 전체 확인 과제 수

숫자가 아직 확인되지 않은 항목은 `집계 중`으로 표시하고 0으로 간주하지 않는다.

### B. 시민 생활로 찾아보기

기관명이 아니라 다음 네 개의 입구를 전면에 배치한다.

1. 내 세금 — 통합비용, 부채, 자산, 퇴직·전산·청사 비용
2. 내 요금 — 전기, 가스, 철도, 항만 비용
3. 내 집 — LH 분리, 공공주택 공급, 주거복지 재정
4. 내 지역·일자리 — 지방이전, 고용승계, 지역서비스 변화

### C. 핵심 감시 과제

초기 공개판에서는 다음 5개만 큰 카드로 노출한다.

1. 발전 5사 통합
2. 석유공사·가스공사 통합
3. LH 개발·주거복지 기능 분리
4. 항만공사 4사 통합
5. 고속철도 일원화와 공공기관 지방이전

나머지는 검색 가능한 전체 장부에 둔다. 후속 결정이 확인된 과제만 별도 상세 카드로 승격한다.

### D. 정부 약속과 실제 결과

각 핵심 과제는 다음 여섯 항목을 나란히 보여준다.

- 정부가 약속한 변화
- 현재 확정된 내용
- 아직 결정되지 않은 내용
- 예상 비용과 공개 여부
- 시민 생활에서 확인할 결과
- 다음 확인 일정

### E. 최근 달라진 사실

단순 기사 추가가 아니라 상태가 바뀐 사건만 노출한다.

- 법안 제출·수정·의결
- 세부 통합안 확정
- 자산·부채·인력 승계안 공개
- 예산과 통합비용 확정
- 실제 법인 출범·청산
- 요금·서비스·주택공급 결과 확인

## 5. 상태 체계

모든 과제는 다음 단계 중 하나만 갖는다.

1. 발표
2. 세부안 마련
3. 법안 제출
4. 국회 심사
5. 의결·공포
6. 시행 준비
7. 조직개편 완료
8. 결과 검증
9. 보류·철회

`정부 발표`와 `개편 확정`, `개편 완료`를 혼용하지 않는다.

## 7. 기사와 출처 표시 원칙

- 화면에 보이는 주요 기사 목록은 언론사 원문을 먼저 배치한다.
- MBC·한겨레·오마이뉴스는 직접·간접 출처와 이미지 출처로 사용하지 않는다.
- 기사 제목·게재일·URL·썸네일을 원문에서 직접 확인한다.
- 모든 언론 기사 카드에는 안정적으로 로딩되는 썸네일이 있어야 한다.
- 정부 자료는 사실 검증과 근거문서 영역에 별도로 연결한다.
- 언론 보도의 전망과 정부·국회가 확정한 결정을 분리한다.
- 확인되지 않은 감축 효과, 비용 절감액, 요금 인하 전망을 확정치로 쓰지 않는다.

## 8. 구독과 재방문 구조

페이지 하단의 일반 뉴스레터 가입만으로 끝내지 않는다. 다음 관심 분야를 선택하는 호출문을 둔다.

- 전기·가스
- LH·주택
- 철도·교통
- 지방이전
- 공공기관 부채·세금

알림 약속은 다음과 같이 구체화한다.

> 법안이 제출되거나, 통합 비용이 공개되거나, 요금·주택·고용에 실제 변화가 생기면 알려드립니다.

초기 배포판에서는 기존 뉴스레터 가입으로 연결하고, 분야별 구독 저장 구조는 별도 개발 과제로 둔다.

## 9. 기존 사이트와의 연결

- 기존 기사 `/news/lh-debt-split-power-five-merge`에서 새 앵커 페이지로 연결한다.
- 시민감시 목록에는 새 페이지를 핵심 이슈감시 항목으로 등록한다.
- 검색과 최신 콘텐츠 목록에 자동 포함되도록 기존 `newsTrackerRegistry` 흐름을 따른다.
- 일반 `LivingWatchDetail`의 타임라인·기사카드 구조는 재사용하되, 30초 요약·생활영향 필터·전체 장부를 위해 전용 상세 컴포넌트를 둔다.
- 기존 검찰청 권한 이동용 문구가 고정된 `authorityMap`은 이 페이지에 재사용하지 않는다.

## 10. 개발 순서

1. 정부 첨부자료와 부처별 후속자료로 전체 과제 장부 확정
2. 핵심 5개 과제의 한국어·영어 콘텐츠 작성
3. 전용 데이터 타입과 자동 집계 함수 구현
4. 앵커 페이지 전용 컴포넌트 구현
5. 언론 기사 원문과 썸네일 확보
6. 기존 기사·시민감시·검색·메타데이터 연결
7. 콘텐츠 검사, TypeScript 검사, 프로덕션 빌드
8. 운영 배포 후 모바일·데스크톱·외부 링크·썸네일 확인
9. 새 사실이 있을 때만 갱신하는 추적 작업 연결

## 11. 첫 공개판의 완료 기준

- 정부 감축 목표 109개의 의미를 오해 없이 설명한다.
- 핵심 5개 과제는 정부 약속·확정 내용·미결 사항이 분리돼 있다.
- 모든 공개 콘텐츠가 한국어와 영어로 제공된다.
- 보이는 언론 기사 카드에는 검증된 썸네일이 있다.
- 공식 근거문서가 별도 영역에 연결된다.
- 시민은 30초 안에 전체 진행 상황을 이해하고, 세금·요금·주택·지역 중 자신의 관심사로 들어갈 수 있다.
- 기존 칼럼과 내용이 중복되지 않고 상호 이동할 수 있다.
