# 씨야 질문 유형과 검색 범위

씨야는 아래 문장을 외워서 답하지 않는다. 질문의 핵심어로 게시된 씨앗 기사와 시민감시 기록을 찾고, 맞는 문단만 AI에 전달해 기사 링크와 함께 답한다. 기사에 근거가 없으면 답을 꾸며내지 않는다. ‘최신 입법’ 질문은 게시된 입법감시 데이터에서 날짜순으로 답한다.

## 실제 질문과 확인된 공백

| 질문 | 개선 전 | 현재 연결 자료 |
| --- | --- | --- |
| 민주란 무엇인가, 민주에 대해 알려줘 | 짧은 질문에서 관련 기사 누락 | 시민언어 ‘민주’와 깊게 읽기 |
| 시민은 누구인가, 씨앗이 말하는 시민은 | 흔한 ‘시민’이 들어간 여러 기사에 밀림 | 시민언어 ‘시민’ 우선 |
| 최신 입법뉴스 알려줘 | 정적 기사 색인에 법안 기록 부재 | 게시된 입법감시 법안 최근 3건을 별도 조회 |
| 여수세계섬박람회 최신 변화 | 이슈감시 추적 페이지 누락 | 여수섬박람회 추적 페이지와 기사 |
| 공공기관 통폐합 현황 | 이슈감시 추적 페이지 누락 | ‘공공기관 109, 정말 줄어드나’ |

## 예상 질문과 표현 패턴

아래는 검색이 연결되어야 할 예시다. ‘최신’이라는 표현은 해당 기사 또는 기록에 적힌 날짜까지만 뜻한다.

### 시민언어와 씨앗의 관점

- 민주란 무엇인가요? / 민주에 대해 알려줘 / 씨앗이 말하는 민주의 뜻은? / 민주주의와 선거는 어떻게 다른가요? / 민주를 깊게 읽어볼 수 있나요?
- 시민은 누구인가요? / 시민에 대해 알려줘 / 씨앗의 시민 개념은? / 국민과 시민의 차이는? / 시민은 어떻게 성장하나요?
- 자유란 무엇인가요? / 시민의 자유와 기업의 자유는 어떻게 이어지나요? / 씨앗은 자유를 어떻게 보나요?
- 보수란 무엇인가요? / 진보는 어떤 뜻인가요? / 보수와 진보의 언어는 왜 달라졌나요?
- 공공과 공익은 무엇이 다른가요? / 공동선은 누구의 것인가요? / 국가가 하면 모두 공공인가요?
- 시민사회는 시민을 대표하나요? / 시민단체와 국가는 어떤 관계여야 하나요? / 기업도 시민이 될 수 있나요?
- 통일에 대한 씨앗의 관점은? / 북한 인권과 통일을 함께 생각해야 하나요?

### 이슈감시

- 공공기관 109개가 실제로 줄어드나요? / 공기업 통폐합 현황은? / 발전 5사 통합은 어떻게 되나요? / 석유공사와 가스공사는 합쳐졌나요?
- 여수세계섬박람회 예산은 얼마인가요? / 여수섬박람회 계약은 어떻게 추적하나요? / 여수세계섬박람회 최근 변화는? / 최초 승인과 현재 행사비의 차이는?
- 검찰청 폐지 뒤 수사는 누가 하나요? / 검찰청 폐지 이슈를 알려줘 / 미제 사건은 어떻게 되나요? / 수사권력은 어디로 가나요?
- 사관학교 통합은 왜 추진하나요? / 사관학교를 합치면 군이 강해지나요? / 통합 과정의 쟁점은?
- 농지 전수조사 결과는? / 농지 처분명령은 어떻게 되나요? / 농지 27% 수치는 확정인가요?
- 김승원 인사청문회 이후 무엇이 달라졌나요? / 남은 수사와 의혹은 무엇인가요?
- 아름다운가게 기부물품은 어디로 갔나요? / 사랑의열매 모금액과 성과는? / 자살예방 예산의 전달 구조는?

### 입법감시와 세금감시

- 최신 입법뉴스 알려줘 / 오늘 나온 법안은? / 최근 공개한 입법감시 기록은? / 이번 주 법안은? / latest legislation?
- 중소기업 판로지원법 개정안은 무엇인가요? / 기업에 실제로 남는 돈은 늘어나나요? / 수사권 이관 관련 법안은?
- 집을 사는 시민의 계좌를 확인하는 법안은? / 운전면허와 가족 신고 관련 개정안은 무엇인가요?
- 코인 과세를 왜 비판하나요? / 가상자산의 이익은 어떻게 계산하나요? / 유류세 인하 비용은 누가 부담하나요?
- 세금감면이 예산지원으로 바뀌면 어떻게 되나요? / 상속세 과세 기준이 왜 문제인가요? / 상속세와 물가상승은 어떤 관계인가요?

### 브리핑과 칼럼

- 오늘의 뉴스에서 상속세를 어떻게 설명했나요? / 가업상속의 사례는? / 기업도 시민이라는 말은 무슨 뜻인가요?
- 배달 플랫폼 광고비 때문에 자영업자가 얼마나 부담하나요? / 공공의료 전달체계의 문제는? / 자살예방에 행안부가 나서야 한다는 이유는?
- 북한군 포로의 한국행 쟁점은? / DMZ 지뢰 사건에 대한 씨앗의 논평은? / 대법관 재선출 논란을 왜 비판했나요?

## 답변 경계

- 씨앗에 게시되지 않은 사안, 개인별 법률·의료·세무 판단, 미래 결과의 단정은 기사 근거가 없으면 답하지 않는다.
- ‘오늘’, ‘최신’, ‘현재’는 게시 날짜를 함께 제시한다. 입법감시 외의 실시간 뉴스 전체를 검색한다고 말하지 않는다.
- 답하지 못한 질문을 편집부에 보내는 일은 독자가 ‘질문 저장’을 눌렀을 때만 한다. 질문을 자동으로 학습하거나 원문을 무단 보관하지 않는다.
